# Goal

## Project
mcp-cli — a python project.

## Description
A command-line interface for interacting with Model Context Protocol (MCP) servers. The CLI provides multiple operational modes (chat, interactive, command), tool management and execution, provider configuration, and rich terminal output. It enables communication with LLMs through MCP servers with features like streaming responses, tool discovery, conversation management, and session persistence.

## Scope
- Core configuration system with defaults, enums, environment variables, and runtime configuration
- Data models for tools, servers, conversation messages, and validation results
- Command system infrastructure with base commands, registry, and parameter handling
- Context management for application state
- Tool management with filtering and validation
- Display formatting and output utilities
- Entry point and main CLI setup
